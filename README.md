# Chainat bathroom, 360° walk-through

Concept design for an accessible ground-floor bathroom, rendered in Blender. Open the page, drag to look around, and tap the green circles or the map to move.

ภาพจำลองห้องน้ำ 360° เปิดหน้าเว็บแล้วลากนิ้วเพื่อหมุนดูรอบ ๆ แตะวงกลมสีเขียวหรือจุดบนแผนผังเพื่อเดินไปจุดอื่น
